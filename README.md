# 🌤️ Prévisions Météo pour la region Boeny

Ce dépôt héberge le site web du **Service Régional de la Météorologie (SRM) Boeny**, montrant les **prévisions météorologiques à 3 jours** pour la région Boeny.

Le site est hébergé directement en ligne via **GitHub Pages** et est accessible depuis n'importe quel navigateur web, sans aucune installation requise.

---

## 📅 Prévisions Météorologiques à 3 Jours (Région Boeny)

Retrouvez sur le site les bulletins et icônes météo réactualisés pour suivre l'évolution des conditions sur la région :

| Jour | Condition Météo | Icône Symbol | Description & Tendances |
| :--- | :--- | :---: | :--- |
| **Jour 1** | Ensoleillé / Nuageux | ☀️ / 🌤️ | Temps ensoleiles prédominant avec développements nuageux locaux l'après-midi. |
| **Jour 2** | Averses / Pluie | 🌧️ / 🌦️ | Risque d'averses orageuses ou de pluies intermittentes sur le littoral et l'intérieur. |
| **Jour 3** | Ciel Dégagé / Vent | 🌤️ / 💨 | Retour d'un temps plus sec avec brise marine modérée le long des côtes. |

*(Les pictogrammes et données détaillées de température et précipitations sont mis à jour dynamiquement sur l'interface).*

---

## 🌟 Ce que montre ce site web

L'interface du site centralise les observations et les outils de suivi pour la région Boeny :

* ☀️ 🌤️ 🌧️ **Prévisions Météo à 3 Jours :** Pictogrammes symboliques et bulletins régionaux pour anticiper le temps (soleil, nuages, averses, orages 🌩️, vent 💨).
* 🌊 🌧️ **Vigilance et alerte :** Suivi des vigilances pour la region Boeny.  
* 🗺️ **Previsions meteo-marines :** Previsions marines et de l'état de la mer.
